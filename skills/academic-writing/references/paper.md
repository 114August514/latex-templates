# 论文流水线（article）

**动手前先读 `writing.md`。** 那份讲论证逻辑——引言的 CARS 模型、
句子怎么排、论文与技术报告的逻辑差异、七类常见的论证硬伤。
本文只讲怎么驱动模板。结构没想清楚就开始排版是最大的浪费。

## 文件分工

| 文件 | 放什么 | 什么时候动 |
|---|---|---|
| `main.tex` | 只有 `\documentclass` 选项和一串 `\input` | 改语言/文献样式/加删章节时 |
| `setup.tex` | 题名、作者、单位、关键词、中图分类号、基金 | 开头填一次 |
| `preamble.tex` | 你自己的宏包、本文专用记号 | 需要新符号时 |
| `acadarticle.cls` | 论文版式（版面、标题层次、标题块、摘要、致谢、附录） | 改样式时 |
| `acadbase.sty` | 三套模板共用的版式 | 改样式且希望报告和幻灯片同步时 |
| `acadmath.sty` | 数学记号 | 加通用符号时 |
| `sections/*.tex` | 正文，不含任何格式命令 | 写作时 |

## 结构顺序（GB/T 7713.2，不要改）

```
题名 → 作者 → 单位 → 摘要 → 关键词 → 中图分类号
→ 引言 → 相关工作 → 方法 → 实验 → 结论
→ 致谢 → 参考文献 → 附录
```

**致谢在参考文献之前，附录在参考文献之后。** 这是最常被写反的一处，
`main.tex` 里的 `\input` 顺序已经排好，不要调换。

## 各节怎么写

### 摘要

报道性摘要，脱离全文能独立成立。结构：目的 → 方法 → 结果（带具体数据）
→ 结论。三条硬约束：

- 不出现「本文」「作者」「我们」这类自指
- 不引用文献编号、不出现图表号
- 不使用非公知缩略语

中文 300 字以内，英文摘要与中文对应但不必逐句直译。

### 引言（漏斗式）

1. 领域重要性与应用背景（1 段）
2. 已有工作及其成果（1–2 段）
3. **已有工作的不足** —— 全文的立论点。要具体到机制，
   「效果不佳」「精度不高」这类话等于没说
4. 本文思路与贡献（分条列，3 条左右）
5. 全文组织（1 段）

第 3 步是引言的重心。写不出具体的不足，说明这篇工作的动机还没想清楚，
这时候应该回去想问题而不是继续往下写。

### 相关工作

按**技术脉络**分小节，不是文献罗列。每小节回答：大家怎么做的 → 共同的
局限 → 与本文的关系。最后一段落回本文的切入点。

### 方法

先给总体结构再给细节。每个公式都要有 `\label` 并在正文里被 `\cref` 引用
——没被引用的公式说明它不必出现。

有理论分析时用 `assumption` / `theorem` / `proof` / `remark` 环境，
它们共用一个计数器连续编号。假设要显式写出来，不要藏在正文里。

### 实验

顺序：数据集与实现细节 → 与现有方法比较 → 消融 → 定性结果。

- 实现细节要写到能复现：硬件、软件版本、随机种子、超参数
- 比较表用 `threeparttable`，把「所有方法在相同配置下复现」这类说明
  放进 `tablenotes`
- 消融要能分离出每个模块的贡献
- 主结果最好带重复实验的波动范围

### 结论

不是摘要的复述。要包含：结果说明了什么（带数据）→ 与已有结论的异同 →
**本研究的局限** → 后续方向。不要引入新数据。

主动写局限。审稿人一定会想到，你先说等于把主动权拿在手里。

## 常用类选项

```latex
\documentclass[
  lang      = zh,       % zh | en
  fontset   = fandol,   % fandol（零配置）| noto（更好看）
  mathstyle = iso,      % iso 遵循 GB/T 3101
  bibstyle  = gb7714,   % gb7714 | gb7714ay | ieee | numeric | authoryear
  % anonymous,          % 盲审：隐去作者/单位/基金/致谢
  % linenumbers,        % 送审加行号
  % print,              % 打印版：超链接转黑
  % twocolumn,
]{acadarticle}
```

投英文期刊时把 `lang=en, bibstyle=ieee` 一起改，正文不用动
（`\cref` 会自动出 Figure/Table，定理名自动变 Theorem/Lemma）。

## 盲审版

加 `anonymous` 就够了，正文一个字不用改：作者、单位、基金、通信作者、
整个 `acknowledgements` 环境都会消失。两个提醒：

- `\end{acknowledgements}` 必须单独成行（`comment` 宏包的限制）
- PDF 元数据和文件名里也别留姓名

## 投稿前自查

```bash
make check
```

再对照走一遍：

- [ ] 致谢在参考文献前，附录在后
- [ ] 摘要无自指、无文献编号
- [ ] 中英文关键词数量一致、一一对应
- [ ] 所有变量斜体、单位正体，函数名用 `\sin` 不是 `sin`
- [ ] 所有单位经 `\qty` 输出
- [ ] 表题在上、图题在下，表为三线表
- [ ] 坐标轴标注为「量 / 单位」
- [ ] 图为矢量格式
- [ ] 参考文献有文献类型标识码，电子资源有引用日期
- [ ] 交叉引用全部走 `\cref`，PDF 里没有 `??`
- [ ] 无 Overfull hbox
- [ ] 结论里的每个数字前文都出现过
