# 报告流水线（report）

**动手前先读 `writing.md`。** 那份讲论证逻辑——引言的 CARS 模型、
句子怎么排、论文与技术报告的逻辑差异、七类常见的论证硬伤。
本文只讲怎么驱动模板。结构没想清楚就开始排版是最大的浪费。

一个类选项覆盖三种形态。先确认是哪一种，封面和骨架都不同：

| `type=` | 用于 | 封面字段 |
|---|---|---|
| `lab` | 课程实验报告 | 课程、实验名、姓名学号、班级、同组人、指导教师、实验/提交日期、成绩栏 |
| `tech` | 科技/技术报告（GB/T 7713.3） | 报告编号、密级、承担单位、编写/审核/批准、日期 |
| `course` | 课程大作业、结课论文 | 学校、院系、课程、题名、姓名学号、日期 |

在 `main.tex` 的 `\documentclass[type=lab, ...]{acadreport}` 里切换，
`setup.tex` 里填对应那一组字段，用不到的留空——留空的字段不会出现在封面上。

## 骨架

`type=lab` 的默认骨架（`main.tex` 里已排好）：

```
实验目的 → 实验原理 → 实验环境与配置 → 实验步骤
→ 数据记录与处理 → 结果分析与误差讨论 → 结论 → 思考题
→ 参考文献 → 附录（原始数据、关键代码）
```

`type=tech` 通常要加摘要和目次，去掉思考题——`main.tex` 里
`\input{sections/00-abstract}` 和 `\tableofcontents` 已经写好，
取消注释即可；思考题那行注释掉。

## 各节怎么写

### 实验目的

要**可检验**。「了解各种优化器」无法判断做没做到；「测定三种优化器达到
90% 准确率所需轮数，并给出置信区间」可以。一般 2–4 条，与结论逐条对应
——这是批阅时最快的检查方式，所以也是最容易失分的地方。

### 实验原理

写到**能据此复现**，但不要抄教材。判据是：读者看完能说出你为什么这么
设计实验。公式的正斜体规则见 `standards.md`。

### 实验环境与配置

对应传统的「实验仪器与材料」。唯一判据是别人能不能复现：

- 物理实验：仪器型号、量程、精度等级、环境温湿度
- 计算实验：硬件、操作系统、CUDA/框架版本、随机种子、超参数

版本号漏一个别人就复现不出来。

### 实验步骤

编号列表，一步一个动作。不要写成流水账，不要把结果混进来。
**控制变量的说明要写清楚**——助教主要看你有没有把不该变的量控制住。

### 数据记录与处理

这一节的核心是**规范地报告带不确定度的数据**：

```latex
\num{93.21(14)}          % → 93.21 ± 0.14（类文件设了 separate-uncertainty）
\qty{94.82(7)}{\percent} % → (94.82 ± 0.07) %
```

表格里用带不确定度的 S 列：

```latex
\begin{tabular}{l S[separate-uncertainty, table-format=2.2(2)]}
  \toprule
  {优化器} & {测试准确率 / \%} \\
  \midrule
  SGD-M & 94.82(7) \\
  \bottomrule
\end{tabular}
```

A 类不确定度评定（重复测量）：

$$\bar{x}=\frac1n\sum x_i,\quad s=\sqrt{\frac{1}{n-1}\sum(x_i-\bar x)^2},\quad u(\bar x)=\frac{s}{\sqrt n}$$

**有效数字保留到不确定度的第一位非零数字**（GB/T 3101、JJF 1059.1）。
`u = 0.068` 应写成 `0.07`，结果写成 `94.82(7)`。

原始数据放附录，正文只放处理后的结果。

### 结果分析与误差讨论

这一节最能拉开差距。合格的分析回答三个问题：

1. **观察到的差异超出随机波动了吗？** 定量判断，不是「明显更好」。
   两组之差的合成不确定度按方和根：$u(\Delta)=\sqrt{u_1^2+u_2^2}$，
   看 $\Delta/u(\Delta)$ 是否大于 2～3。
2. **差异的来源是什么？** 机制解释，不是复述数字。
3. **有哪些系统误差没被消掉？** 用一张表列出「来源 / 类型 / 处理方式」，
   诚实写出「未消除」的项。藏起来的分比写出来扣得多。

### 结论

与实验目的逐条对应。每个数字前文都出现过。

### 思考题

拉分项。答案要有推导或数据支撑，不要写「我觉得」。尽量引用自己前面的
公式和表格（`\cref{eq:...}`、`\cref{tab:...}`），显示前后是通的。

## 代码清单

`preamble.tex` 里配好了 `listings`：

```latex
\begin{lstlisting}[language=Python, caption={随机种子设置}, label={lst:seed}]
def set_seed(seed): ...
\end{lstlisting}
```

行内代码用 `\lstinline|torch.manual_seed|`。贴代码只贴关键部分，
完整代码放附录或随报告提交的目录。

## 最容易失分的三处

1. **只报最好的一次结果。** 不给重复次数和波动范围，结论无法被判断可靠性。
2. **用测试集选点。** 让测试集参与模型选择，报出来的指标是有偏的乐观估计。
3. **实验目的和结论对不上。** 目的列了 4 条，结论只答了 2 条。
