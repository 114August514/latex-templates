# 学术演示的设计与答辩策略

> **来源说明**：本文档写作时环境里的联网检索工具不可用，内容出自编写者
> 掌握的知识。为了让你能判断可信度，下面**明确区分了三类**：
> 【实证】有对照实验或认知心理学实验支撑；
> 【惯例】学界广泛共识但没有实验证据；
> 【民间】流传很广但证据薄弱甚至是误传——列出来是为了让你别照做。
> 【实证】部分给了出处，建议你按出处自己核一遍。

`slides.md` 讲怎么驱动模板，本文讲**放什么内容、怎么讲、答辩怎么打**。

## 一、有实证支撑的部分

### 1.1 Assertion-Evidence 结构 【实证】

出处：Michael Alley（宾夕法尼亚州立大学），*The Craft of Scientific
Presentations*；及其与 Schreiber、Ramsdell、Muffo 等人发表的对照研究。

**默认的幻灯片结构是错的。** PowerPoint 的默认版式是「名词短语标题 +
一串 bullet」（topic-subtitle）。Alley 的研究比较了它和另一种结构：

| | 默认结构 | Assertion-Evidence |
|---|---|---|
| 标题 | 名词短语：「实验结果」 | **完整句子**：「门控使小目标 AP 提升 6.2 个百分点」 |
| 正文 | 一串 bullet | **一块视觉证据**（图/表/示意） |

实验测到 AE 结构下听众的**理解与留存**更好。机制解释是：名词短语标题
把「结论是什么」这一步留给听众自己完成，而完整句子直接给出结论，
视觉证据则支撑它——听众的认知资源用在验证而不是猜测上。

**怎么落地**：模板提供了 `evidence` 环境与 `\takeaway{}`：

```latex
\begin{frame}{门控使小目标 AP 提升 6.2 个百分点}
  \begin{evidence}
    \includegraphics[width=0.8\linewidth]{ablation}
  \end{evidence}
  \takeaway{增益集中在小目标，说明提升来自特征保留而非分类能力}
\end{frame}
```

**自查**：把你的幻灯片标题抄成一列。如果读这一列读不出一个完整的故事，
说明标题写成了名词短语。这一条是投入产出比最高的改动。

### 1.2 认知负荷与多媒体学习原则 【实证】

出处：Richard Mayer, *Multimedia Learning*；Sweller 的认知负荷理论。
这些是几十年的实验心理学结果，对幻灯片的直接推论：

- **冗余原则（redundancy）**：同时呈现「口述的话」和「与之逐字相同的文字」
  会**降低**理解效果，因为听众要同时处理两路等价信息。
  → 推论：**不要把讲稿打在幻灯片上，也不要念幻灯片。**
  这是「不要念 PPT」这条老生常谈唯一的实验依据。

- **信号原则（signaling）**：用视觉线索指出该看哪里，能提升学习效果。
  → 推论：图上要加箭头、圈、高亮；关键数字用 `\alert{}`。
  模板的强调色就是干这个的。

- **空间邻接原则（spatial contiguity）**：文字应贴近它描述的图像部分，
  而不是分开放。
  → 推论：**图注不要放在图很远的地方**，标注直接压在图上。

- **连贯原则（coherence）**：删掉与目标无关的内容（包括装饰性图片、
  背景音乐、无关的动画）**能提升**学习效果。
  → 推论：模板不给花哨的背景与转场，不是保守，是有依据的。

- **分段原则（segmenting）**：把内容切成听众可控的小段，比一次全给更好。
  → 推论：`\pause` / `\onslide<2->` 的逐步揭示是有依据的；
  但那是**分段**，不是**动画**——不要用飞入飞出。

## 二、行业惯例（无实验，但是共识）

### 2.1 时长与页数预算 【惯例】

经验系数：**正文平均每页 40~60 秒**。标题页、节页、致谢页不计。
备用页不计。

| 场合 | 讲述时长 | 正文页数 | 备用页 |
|---|---|---|---|
| 组会汇报 | 10~15 min | 10~15 | 3~5 |
| 会议 oral | 12~15 min | 12~18 | 3~5 |
| 开题答辩 | 15~20 min | 15~20 | 5~8 |
| 中期答辩 | 15~20 min | 15~20 | 5~10 |
| 硕士答辩 | 20~25 min | 20~28 | 8~15 |
| 博士答辩 | 30~40 min | 30~45 | 15~25 |

**页数超了就删内容，不要靠加快语速。** 加快语速是答辩中最常见的失控方式，
一旦开始赶，后面每一页都会更赶。

### 2.2 答辩内部的时间分配 【惯例】

20 分钟的硕士答辩，一个稳的分配：

```
选题背景与意义      2 min   ██
研究现状与问题      2 min   ██
研究内容与路线      1 min   █
工作一              5 min   █████
工作二              5 min   █████
结论与创新点        3 min   ███
成果与工作量        1 min   █
致谢                0.5 min ▌
```

**最常见的失分方式：背景讲了 8 分钟，自己的工作只剩 6 分钟。**
委员会评的是你做了什么，不是你读了什么。背景部分你最熟、最不紧张，
所以最容易讲超——排练时专门掐这一段的表。

### 2.3 字号与可读性 【惯例】

- 正文不小于**等效 20 pt**。16:9 版面下 beamer 的 `\normalsize`（11pt 基准）
  已接近这个下限，所以**不要为了塞内容调小字号**——塞不下就拆帧。
- 一帧的文字量上限：大约 6 行 × 每行 10 个汉字。超了就是在写文档不是做幻灯片。
- 代码字号可以小一号，但**只贴关键的 5~10 行**，全文放备用页。

### 2.4 比例与动画 【惯例】

- **16:9**：现在会场投影与线上会议的默认，4:3 已基本淘汰。模板默认如此。
- 动画只用 `\pause` / overlay 做**逐步揭示**（有 segmenting 原则支撑），
  不用飞入、旋转、转场（被 coherence 原则否定）。
- 页码用 `n/N`：听众提问时能报出位置，模板已配。

## 三、流传很广但别照做的 【民间】

- **「一页不超过 7 行，因为工作记忆是 7±2」** —— Miller 1956 的 7±2 说的是
  *无意义音节的短期记忆容量*，和幻灯片行数没有关系，且后续研究认为
  实际容量更接近 4。少放内容是对的，但理由是认知负荷，不是这个数字。

- **「听众注意力只有 10 分钟 / 20 分钟」** —— 这个说法的实验基础很薄弱，
  被反复引用但溯源不到可靠出处。真正成立的是：**没有结构的内容**很快
  失去注意力，有结构的可以维持很久。所以解法是把结构讲清楚，
  不是把报告压到 10 分钟。

- **「每页只放一张图，不要文字」** —— 过度简化。AE 结构要求的是
  「标题是完整句子 + 证据是视觉」，不是「不许有文字」。
  必要的标注、坐标轴标签、takeaway 一句话都该有。

- **「深色背景更护眼/更专业」** —— 取决于场地照明。**明亮会场用浅底深字**
  （投影仪的黑色其实是「不发光」，环境光一亮就发灰）；只有全暗的
  报告厅深底才有优势。模板默认浅底，因为绝大多数答辩教室是亮的。

## 四、答辩专有

### 4.1 答辩和会议报告的目标不同

| | 会议 oral | 学位答辩 |
|---|---|---|
| 听众 | 陌生同行，没看过你的论文 | 委员会，**手里有你的论文全文** |
| 目标 | 让人觉得这个想法有意思 | 证明这份工作**够一个学位** |
| 可以取舍吗 | 可以只讲一条最亮的线 | 必须覆盖全部工作量与创新点 |
| 局限怎么处理 | 一笔带过 | **主动、明确地讲出来** |
| 提问 | 好奇性提问 | 核验性提问，会追着薄弱处问 |

最关键的差别是**听众手里有全文**。这意味着：藏不住的东西不要试图藏，
你跳过的地方委员会知道你跳过了。

### 4.2 国内学位答辩的结构期待 【惯例】

相当固定，`defense/` 模板已经按这个排：

```
选题背景与意义 → 国内外研究现状与存在问题 → 研究内容与技术路线
→ 工作一 → 工作二 → 结论与创新点 → 成果与工作量 → 致谢
```

两个中国特色、国际会议模板里没有的：

- **「创新点」单独成节**。委员会拿它对照学位授予标准，所以要能被逐条核对：
  2~3 条（多了显得每条不够分量），句式是「针对……问题，提出了……，
  实现了……（带数据）」，每条都要能指回前面某一页。
- **「成果与工作量」单独成页**。论文按「作者顺序、刊物全称、级别、状态」列，
  状态要写实：已发表 / 已录用 / 在审 / 已投稿，不要模糊成「发表」。
  在审的要写投稿时间，委员会据此判断进度合理性。

### 4.3 开题 / 中期 / 毕业的差别

| | 开题 | 中期 | 毕业 |
|---|---|---|---|
| 背景与意义 | **4~5 页，重点** | 2 页 | 2 页 |
| 研究现状 | **详细，要论证 gap** | 简略 | 简略 |
| 技术路线 | **3~4 页，含时间计划** | 2 页，标出已完成/未完成 | 1~2 页 |
| 已完成工作 | 无或预实验 | **重点** | **重点** |
| 创新点 | 预期创新点（用「拟」） | 已实现 + 待实现 | 已实现 |
| 成果 | 无 | 阶段成果 | **完整列表** |

用 `defense/` 模板做开题或中期时，按上表调整各节页数，
把「成果与工作量」一节删掉或改成「阶段进展」。

### 4.4 提问会问什么

按出现频率排，每一类都该有备用页：

1. **假设是否成立** ——「你这个独立性假设实际满足吗」
   → 备用页放实测数据，诚实说「不严格成立，但影响有界」。
2. **对比是否公平** ——「对比方法调优了吗」「为什么不比某某方法」
   → 备用页放实验配置、复现说明、以及你没比的方法为什么不可比。
3. **创新性有多少** ——「这和某某工作的区别是什么」
   → 备用页放逐篇对比表。这是最需要提前准备的一类。
4. **结论能推多远** ——「换个数据集/模态还成立吗」
   → 有初步实验就放，没有就明确说「未验证，是后续工作」。
5. **工作量够不够** ——多见于硕士答辩
   → 成果页 + 代码/数据集/工程量的证据。
6. **细节核验** ——「第 43 页那个公式的推导」
   → 完整推导放备用页。

### 4.5 备用页策略

会议报告的备用页是「可能有人问」，答辩的备用页是「**一定会被问，
而且问的人手里有全文**」。

**准备方法**：把论文里每一处你自己觉得心虚的地方列出来——假设不严格、
对比不充分、参数没调、样本量小、结论外推——每一条准备一页。
硕士通常 8~15 页，博士 15~25 页。宁可多准备用不上，不要被问住。

模板提供了跳转机制（用的是 beamer 自带的 `[label=]`，没有额外魔法）：

```latex
% 备用页
\begin{frame}[label=bk:proof]{完整证明}
  ...
  \returnbutton{main:end}
\end{frame}

% 索引页
\begin{frame}[label=bk:index]{备用页索引}
  \backuplink{bk:proof}{方差不增的完整证明}
\end{frame}
```

问答时先跳索引页，再点条目；答完点「返回」回到致谢页。
**答辩前一定要在实际播放器里试一遍跳转**——有些 PDF 阅读器的
全屏模式不响应超链接，那就得靠记页码，用 `n/N` 的 N 心算。

### 4.6 防守姿态

- **主动说局限。** 委员会一定会想到，你先说出来，主动权就在自己手里；
  等被问出来，性质就从「你知道边界」变成「你没想到」。
- **陈述，不要道歉。** 说「该方法在层间强相关时界会变松」，
  不要说「这里做得还不太好，不好意思」。前者是研究者的语气，
  后者会诱发更多追问。
- **不知道就说不知道**，然后给出你会怎么查。硬编一个答案，
  委员会通常当场就能听出来，代价比承认大得多。
- **被指出错误时先确认再回应。** 「您是说……对吗」——一是确保理解正确，
  二是给自己几秒思考。

## 五、视觉

### 5.1 对比度与色觉缺陷

投影仪的对比度普遍低于显示器，环境光还会进一步压缩，所以显示器上
「刚好能看清」的颜色在会场上往往不行。

模板配色是量化验证过的：所有前景色对白底、以及对 block 的浅底
`AcadWash`，WCAG 对比度均 ≥ 4.5（AA 正文标准）；三个语义色在
绿色盲与红色盲模拟下两两 ΔE\*ab ≥ 38，可靠区分。

**注意 block 的背景不是纯白。** 只按白底调色，会在 block 里掉到 AA 以下——
这是个真实存在过的 bug。

**换配色后重验的脚本**（无依赖，直接跑）：

```python
import itertools, math
def s2lin(c):
    c/=255; return c/12.92 if c<=0.04045 else ((c+0.055)/1.055)**2.4
def lin2s(c):
    c=max(0.,min(1.,c)); return round(255*(12.92*c if c<=0.0031308 else 1.055*c**(1/2.4)-0.055))
def lum(rgb):
    r,g,b=map(s2lin,rgb); return .2126*r+.7152*g+.0722*b
def cr(a,b):
    la,lb=lum(a),lum(b); return (max(la,lb)+.05)/(min(la,lb)+.05)
def simulate(rgb, kind):                      # Viénot-Brettel-Mollon 1999
    R,G,B=map(s2lin,rgb)
    L=17.8824*R+43.5161*G+4.11935*B
    M=3.45565*R+27.1554*G+3.86714*B
    S=0.0299566*R+0.184309*G+1.46709*B
    if kind=='protan': L=2.02344*M-2.52581*S
    if kind=='deutan': M=0.494207*L+1.24827*S
    if kind=='tritan': S=-0.395913*L+0.801109*M
    r= 0.0809444479*L-0.130504409*M +0.116721066*S
    g=-0.0102485335*L+0.0540193266*M-0.113614708*S
    b=-0.000365296938*L-0.00412161469*M+0.693511405*S
    return tuple(lin2s(x) for x in (r,g,b))
def lab(rgb):
    r,g,b=map(s2lin,rgb)
    X=(.4124*r+.3576*g+.1805*b)/.95047; Y=.2126*r+.7152*g+.0722*b
    Z=(.0193*r+.1192*g+.9505*b)/1.08883
    f=lambda t: t**(1/3) if t>.008856 else 7.787*t+16/116
    fx,fy,fz=f(X),f(Y),f(Z); return (116*fy-16,500*(fx-fy),200*(fy-fz))
dE=lambda a,b: math.dist(lab(a),lab(b))

WHITE=(255,255,255); WASH=(243,245,248)
FG={'primary':(11,61,107),'secondary':(150,90,14),'accent':(0,102,86),
    'ink':(28,32,38),'muted':(99,104,111)}
for k,v in FG.items():                        # 目标：两列都 ≥ 4.5
    print(f'{k:<10} 白底 {cr(v,WHITE):5.2f}  浅底 {cr(v,WASH):5.2f}')
sem=['primary','secondary','accent']
for kind in ('normal','deutan','protan','tritan'):   # 目标：ΔE ≥ 20
    sim={k:(FG[k] if kind=='normal' else simulate(FG[k],kind)) for k in sem}
    print(kind, min(dE(sim[a],sim[b]) for a,b in itertools.combinations(sem,2)))
```

**更重要的一条规则：不要只靠颜色编码信息。** 色觉缺陷、黑白打印、
投影偏色都会让纯颜色编码失效。图例、标记形状、直接文字标注要跟上。

### 5.2 图表

- 论文里的图**不能直接搬到幻灯片**。论文图是给能反复看的读者的，
  幻灯片图是给看 40 秒的听众的。要删线、放大字号、去掉次要系列。
- 表格比论文里**再删一半**：只留支撑当前论点的行与列，完整表放备用页。
- 关键数字用 `\alert{}` 或加粗指出该看哪个（signaling 原则）。
- 坐标轴标注写「量 / 单位」，如 `t / s`（GB/T 3101 推荐斜杠形式）。
- 图必须矢量（PDF），matplotlib 用 `plt.savefig('x.pdf')`。

## 六、排练

【惯例】但几乎所有讲得好的人都这么做：

1. **掐表全程讲一遍，不停。** 卡住也不要重来——真实答辩不会让你重来。
2. **专门掐背景那一段的表**，它最容易超。
3. **对着人讲一遍**，哪怕是室友。自己对着屏幕讲发现不了问题。
4. **写演讲备注。** 紧张时讲稿是唯一的锚。模板支持
   `\note{}` + `make notes` 生成双屏版，配 pdfpc 播放。
   备注写「这里要强调什么」「预判的提问怎么答」，不要抄幻灯片上已有的字。
5. **在实际设备上试一遍**：字号在投影上够不够大，颜色会不会偏，
   超链接跳转响不响应，字体有没有掉。
6. **准备开场第一句和最后一句**，逐字背下来。这两句最容易慌。
