# 排版规范速查

写任何一种产物时遇到「这个该怎么排」都查这里。完整版在模板目录的
`STANDARDS.md`，那份带每条规则的标准编号出处。

## 正斜体（GB/T 3101—1993 / ISO 80000-2:2019）

评审最容易挑刺、也最容易系统性写错的地方。

| 对象 | 字体 | 模板里的写法 |
|---|---|---|
| 量符号（变量） | **斜体** | `$m$`、`$T$` |
| 单位符号 | **正体** | `\unit{\kg}` |
| 数学常数 e、π、i | **正体** | `\e`、`\symup{\pi}`、`\ii` |
| 微分算子 d | **正体** | `\dd x` |
| 函数名 | **正体** | `\sin`、`\log`、`\argmin` |
| 矢量、张量 | **粗斜体** | `\vect{F}`、`\tens{\sigma}` |
| 矩阵 | 粗斜体（全文统一） | `\mat{A}` |
| 转置上标 | **正体** | `\transpose` |
| 数集 ℝ ℤ ℕ | 黑板粗正体 | `\R`、`\Z`、`\N`（复数用 `\Cplx`） |
| 下标是量的 | 斜体 | `$C_p$` |
| 下标是说明文字的 | **正体** | `E\subtext{max}`，不要写 `E_{max}` |
| 化学元素符号 | 正体 | `\mathrm{Fe}` |

`mathstyle=iso` 类选项会让大写拉丁/希腊字母作变量时也用斜体，这是国标
要求；期刊若沿用传统 TeX 习惯就改成 `mathstyle=tex`。

## 量与单位（GB 3100 / siunitx）

```latex
\qty{5}{\kg}                % 5 kg，数值与单位间自动窄空格
\qty{25}{\degreeCelsius}    % 25 °C
\unit{\m\per\s}             % m/s，只有单位
\num{1.2e-3}                % 1.2×10⁻³
\num{1234567}               % 1 234 567，窄空格分节
\numrange{5}{10}            % 5~10
\qty{94.82(7)}{\percent}    % (94.82 ± 0.07) %
```

**不要手写 `5 kg`。** 间距、正斜体、分节符都由 siunitx 按标准处理。

例外：平面角的度分秒与百分号不留空格——`30°`、`50%`，siunitx 已处理。

## 数字用法（GB/T 15835—2011）

- 计量数字、编号用阿拉伯数字：`3 个样本`、`第 5 章`
- 概数、成语、固定词组用汉字：`三四天`、`三分之一`
- 4 位以上分节用**窄空格**不用逗号：`1 234 567`
- 数值范围用浪纹线，单位只写一次：`5~10 kg`

## 参考文献（GB/T 7714—2015）

两种体系，全文统一：顺序编码制（理工科绝大多数）或著者—出版年制。

必须标**文献类型标识码**，这是 GB/T 7714 区别于 IEEE/APA 的最显著特征：

| `[J]` 期刊 | `[M]` 专著 | `[C]` 论文集 | `[D]` 学位论文 |
|---|---|---|---|
| `[R]` 报告 | `[S]` 标准 | `[P]` 专利 | `[EB/OL]` 网络资源 |

`.bib` 里的注意事项：

```bibtex
@article{key,
  langid = {chinese},   % 中文文献必写，样式据此切换「等」/「et al.」
  ...
}
@online{key,
  urldate = {2026-07-26},   % 电子资源必须有引用日期
  ...
}
```

著者超过 3 位列前 3 位加「等」——`maxbibnames=3` 已配好，不用手动截断。

切换样式只改类选项，`.bib` 不用动：

```latex
bibstyle = gb7714      % 顺序编码制
bibstyle = gb7714ay    % 著者—出版年制
bibstyle = ieee        % 投英文期刊
```

## 图表

- **表题在表上方，图题在图下方**（跨所有规范一致）
- 表格用三线表：`\toprule` `\midrule` `\bottomrule`，不画竖线
- 数字列用 siunitx 的 `S` 列按小数点对齐
- 表注用 `threeparttable` 的 `tablenotes`
- 图必须矢量（PDF/EPS），位图不低于 600 dpi
- 坐标轴标注写「量 / 单位」：`t / s`，不写 `t (s)`
- 子图编号 `(a) (b) (c)`，标在子图下方

## 交叉引用

```latex
\cref{fig:arch}    % → 图 3      （lang=en 时 → Figure 3）
\cref{eq:gate}     % → 式 (5)
\cref{tab:main}    % → 表 2
\cref{thm:var}     % → 定理 1
\cref{sec:method}  % → 节 3
```

类型词自动生成，中英切换不用改正文。每个图表公式都要有 `\label`，
命名用 `fig:` `tab:` `eq:` `alg:` `sec:` `thm:` 前缀。

## 中英混排（CY/T 154—2017）

- 中英文之间**不手动加空格**，由 xeCJK 自动插入可伸缩间距，
  手打空格会破坏对齐
- 中文句子里的英文单词后仍用中文标点
- 中文里用全角括号 `（）`，纯英文内容用半角 `()`
- 中文没有真斜体，不要对中文用 `\textit`（模板已禁用伪斜）

## 结构顺序（GB/T 7713）

```
前置部分：题名 → 作者 → 单位 → 摘要 → 关键词 → 中图分类号
主体部分：引言 → 正文 → 结论
结尾部分：致谢 → 参考文献 → 附录
```

**致谢在参考文献之前，附录在之后。** 最常写反的一处。
